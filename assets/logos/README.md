# Logo sources

These assets are stored locally so the profile does not depend on an icon service at render time. Product names and logos belong to their respective owners.

| Assets | Source | License / permission |
| :--- | :--- | :--- |
| TypeScript, JavaScript, Java, C, C++, C#, Python, React, Next.js, .NET, Tailwind CSS, OpenCV, Git, Vite, CMake, Supabase, Vercel | [Skill Icons](https://github.com/tandpfun/skill-icons), downloaded from `https://skillicons.dev/icons?i=ICON_ID&theme=dark` | [MIT license](SKILL-ICONS-LICENSE.txt) |
| SQL | Generic database symbol drawn for this profile | Original SVG; represents SQL without using a database vendor's logo. |
| Dear ImGui | [Banner shared by maintainer Omar Cornut](https://github.com/ocornut/imgui/discussions/6676) | The maintainer explicitly permits using the banner in the linked discussion. The original image is preserved. |
| Windows Forms | [Microsoft's Windows Forms icon resource](https://github.com/dotnet/winforms/blob/main/src/System.Windows.Forms/Resources/System/Windows/Forms/wfc.ico), converted from ICO to PNG | [MIT license](DOTNET-WINFORMS-LICENSE.txt) |

Skill Icons IDs, in the order listed above: `ts`, `js`, `java`, `c`, `cpp`, `cs`, `py`, `react`, `nextjs`, `dotnet`, `tailwind`, `opencv`, `git`, `vite`, `cmake`, `supabase`, `vercel`.

`dear-imgui.svg` and `windows-forms.svg` embed their original raster assets at the README's display dimensions, allowing standard Markdown images without inline HTML.
